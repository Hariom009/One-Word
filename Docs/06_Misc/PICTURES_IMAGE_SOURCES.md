# Picture Book — image sources

Every photo in `OneWord/Pictures/` comes from Wikimedia Commons and carries a **CC0** or
**public-domain** mark there (checked twice: the Commons search filtered on the structured
licence / copyright-status statements, then each file's own `LicenseShortName`). Neither
needs attribution; the author column is kept as a courtesy and so a file can be traced back.

Pulled 2026-10-23. Candidates were found three ways: a title search, Wikidata "depicts" of
the word's Wikipedia article, then a plain text search for what was still missing. One photo
per word was chosen by eye from six candidates. Each was resized to ≤800px on the long side
and saved as JPEG q72.

Cut for want of a usable free photo: axe, ball, curtain, ear, hourglass, kangaroo, magnet,
nose, telescope, yo-yo. Tooth was cut because its only photo was a dental close-up, and pomegranate
because every usable photo was under 350px.
Weakest keepers, worth swapping if a better CC0 photo turns up: umbrella, shirt, shoe, cave,
volcano (a satellite view), hammer (shot beside a colour chart), island (a satellite view).
